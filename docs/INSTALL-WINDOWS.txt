KINETIK JUNGLE (KJNG-2) - installation sous Windows
===================================================

1. Copier le dossier "Kinetik Jungle.vst3" (tout le dossier) dans :
       C:\Program Files\Common Files\VST3
   (Windows demande une autorisation administrateur : accepter.)
   IMPORTANT : supprimer l'ancien dossier "J-Slice.vst3" de ce même dossier (c'est le même plugin
   sous son ancien nom ; tes projets Ableton qui l'utilisaient s'ouvrent avec Kinetik Jungle).

2. Ableton Live 12 : Options > Settings (Préférences) > Plug-Ins
   - activer "Use VST3 Plug-In System Folders"
   - cliquer sur "Rescan"

3. Dans le navigateur d'Ableton : Plug-Ins > Kozzzmo > Kinetik Jungle.
   Glisser Kinetik Jungle sur une piste MIDI (c'est un instrument).

4. Charger un break : cliquer sur la carte A (ou BROWSE, ou glisser un fichier WAV/AIFF/FLAC/MP3/OGG
   sur la forme d'onde A), puis lancer la lecture dans Ableton.
   Un deuxième break se charge sur la ligne B : ses coups viennent se placer dans les trous du break A.

"Kinetik Jungle.exe" est une version autonome (sans Ableton) pour tester rapidement.
Windows peut afficher un avertissement SmartScreen car le programme n'est pas signé :
"Informations complémentaires" > "Exécuter quand même".

Le dossier demo-loops contient des boucles générées par les tests automatiques
à partir d'un break synthétique (pour avoir une idée des styles).
